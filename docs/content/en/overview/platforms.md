# Platforms Supported

*FlagGems* supports 10+ backends. The currently supported platforms and
their capabilities are listed below:

| Vendor     | Vendor name   | State | float16 | float32 | bfloat16 |
| ---------- | ------------- | ------| ------- | ------- | -------- |
| AIPU       | `aipu`        | ☑️     | ✅      | ✅      | ✅       |
| AMD        | `amd`         | 🚧    | -       | -       | -        |
| ARM(CPU)   | `arm`         | ☑️     | -       | -       | -        |
| Ascend     | `ascend`      | ✅    | ✅      | ✅      | ✅       |
| Cambricon  | `cambricon`   | ✅    | ✅      | ✅      | ✅       |
| Hygon      | `hygon`       | ✅    | ✅      | ✅      | ✅       |
| Iluvatar   | `iluvatar`    | ✅    | ✅      | ✅      | ✅       |
| Kunlunxin  | `kunlunxin`   | ✅    | ✅      | ✅      | ✅       |
| MetaX      | `metax`       | ✅    | ✅      | ✅      | ✅       |
| Mthreads   | `mthreads`    | ✅    | ✅      | ✅      | ✅       |
| NVIDIA     | `nvidia`      | ✅    | ✅      | ✅      | ✅       |
| Sunrise    | `sunrise`     | ☑️     | ✅      | ✅      | ✅       |
| TsingMicro | `tsingmicro`  | 🚧    | -       | -       | -        |

**Legend**:

- ✅ - supported
- ☑️  - partially supported
- 🚧 - under development
